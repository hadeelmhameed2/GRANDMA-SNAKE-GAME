## ✨ Features

* 🎨 **Custom Graphics:** Swap boring squares for a cartoon snake, tasty cupcakes, and bubbling potion bottles.
* 🚀 **Progressive Difficulty:** The game speeds up as you score, with poison obstacles spawning at Level 5!
* 🕹️ **Full UI System:** Includes a lively main menu, pause functionality, a live HUD, and a custom Game Over screen.
* 💾 **Persistent Scoring:** High scores are saved directly to your browser's local storage.
* 🎵 **Safe Audio Playback:** The game is coded to handle missing audio files gracefully without crashing.

## 🎮 How to Play

1. **Clone or Download** the repository to your local machine.
2. **Run it:** Open `index.html` in any modern web browser. No server required!
3. **Controls:** Click **PLAY** and use the ⬆️ ⬇️ ⬅️ ➡️ **Arrow Keys** to steer.
4. **Objective:** Eat cupcakes to grow, but avoid the walls, your tail, and the purple poison!

## 🎧 A Note on Music (Optional)

To keep this repository lightweight and avoid copyright issues, the background music file is not included. 
* The game is built to run perfectly in silence. 
* If you want to enable background music on your local machine, simply download an MP3 file, name it `music.mp3`,
  
      and place it in the root folder alongside `index.html`. The game will automatically detect and play it!
